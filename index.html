Privacy and permissions

An extension that edits what websites see should be easy to audit. This is everything VCam Bypass asks for and why. The code is short, public and licensed under the GPL.

  • Runs on every site

    It must patch the camera APIs before a page's own scripts run, so it is injected on all pages. It only rewrites device info and never reads page content.

  • Settings stay on your device

    The storage permission keeps your choices in the browser. Nothing is uploaded and there is no account.

  • One request to GitHub

    When the browser starts, it asks the GitHub API for the latest release number so the popup can show an update badge. It sends no cookies and no identifiers.

  • No tracking, no remote code

    No analytics, no ads and no servers of its own. This site does not track you either.

The only official source is the GitHub repository. Copies in extension stores are not made or endorsed by the author. You are responsible for following the laws and terms of service that apply where you use it.

Questions

Does it change my video?

No. It only rewrites the device information the browser reports: name, IDs and capabilities. The stream keeps its real resolution and frame rate, so the video looks exactly as it does without the extension.

Which virtual cameras work?

Any virtual camera that shows up as a webcam in Chrome, such as OBS Virtual Camera, ManyCam, DroidCam, iVCam or Snap Camera. It must be installed and running before you pick it.

Why do I have to reload the page?

The mask is applied when a page starts loading. After installing the extension or changing a setting, reload the tab where you use the camera.

Which browsers are supported?

Chrome, Edge and Brave, or any Chromium browser that supports Manifest V3 extensions.

Will it work on every website?

It changes what the browser's camera APIs report to the page. A service that identifies virtual cameras in some other way, for example on its own servers or outside the browser, is out of its reach. Use the Test it button to check what a site sees.

How do I update it?

When a new release is out, the popup shows a badge. Replace the folder's files with the new version and click reload on the extension card.

Something is not working. Where do I report it?

Open an issue on GitHub with your browser version, the virtual camera you use and what the Test it page shows.
