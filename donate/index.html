Questions

Where does the money go?

Into the time the project takes: looking for new masking methods, adding webcam profiles, keeping up with changes to the Chrome extension APIs, fixing bugs, etc.

Is the extension free?

Yes, and it stays that way. It is GPL-3.0 licensed, so you can use, fork, and modify it. Donations are voluntary and do not unlock features or grant priority support. If you need something specific, open an issue on the repository or message me on Discord: _Viada

Can I send from an exchange?

Yes, but confirm that the exchange allows withdrawals to an external wallet on that specific network. Sending an asset on the wrong network usually means the funds are lost for good.
